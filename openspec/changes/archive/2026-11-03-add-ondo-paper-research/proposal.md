# 提案：Ondo／Lighter 单标的录制与模拟验证

## Why

做市补贴的收益取决于有效挂单竞争、成交后对冲成本及异常行情。现有分享没有可复现数据，不能据此认定稳定年化或最大亏损。先用一个小型研究工具验证数据和成本，再考虑真实交易。

## What Changes

- Python 3.11+，仅用标准库；命令行、单进程、SQLite，一个配置文件，一个标的，默认 INTC。
- 通过两家的公开只读 REST 接口按约 2 秒间隔录制盘口；启动时查询 Lighter 市场 ID，不硬编码 ID。
- 保存原始响应、规范化盘口、各自接收时间、可获得的交易所时间、配置、元数据和失败记录。
- 离线回放模拟 Ondo 双边 Post-only 报价，以及成交后延迟在 Lighter 对冲；计算费用、未平仓风险和模拟损益。
- 提供离线演示数据和中文说明，不需要账户、密钥或额外服务。

## 方案比较与选择

1. 仅录制行情：最小，但不能发现对冲成本和状态错误。
2. 录制＋透明的简化模拟（选择）：多一个模拟器，能用可追溯的假设评估风险。
3. 实盘机器人：需要签名、订单状态对账和资金风控，留待后续单独提案。

## 第一版明确不做

真实下单、撤单、转账、API 密钥、网页界面、WebSocket、高频套利、多标的、多进程服务、自动奖励领取、自动计算官方奖励份额、强平／保证金仿真。目录沿用用户指定的 pendle，但研究标的是 Ondo 与 Lighter。

## 验收

离线 demo、录制和回放有可执行命令；网络失败明确落库；同一数据与配置回放结果一致；能解释每笔模拟成交／对冲；风险触发后停止新增报价并显示残留风险。通过 unittest、编译检查、OpenSpec 严格验证及两位 agent 审核。真实公开 API 做短时烟测，不能代替长期采样。

## Impact

新建项目，无既有代码或用户状态需要迁移。无 graphify-out/graph.json，因此不触发 Graphify 检查。所有网络操作限定官方公开行情 GET。录制文件本地保存，不包含账户信息。

## 审核与授权

用户已授权：先提案，由两个 agent 独立审核，无阻塞问题后开发；主 agent 全程负责整合和验证。审核不等于批准实盘交易。
